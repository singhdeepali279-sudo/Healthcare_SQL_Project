# 🏥 Healthcare SQL Project

## 📌 Project Overview
This project demonstrates SQL-based data cleaning and analysis using a healthcare dataset. The objective is to improve data quality, identify inconsistencies, and prepare the dataset for analysis.

## 🎯 Business Objective
- Clean healthcare data for better accuracy.
- Handle missing values and duplicate records.
- Standardize the dataset.
- Prepare data for reporting and analytics.

## 📂 Dataset
The project uses the following files:
- diabetic_data.csv
- Inpatient_Admission_Description.csv
- Outpatient_Admission_Description.xlsx
- Discharge Description.xlsx

## 🛠 Tools Used
- MySQL
- GitHub

## 🔍 SQL Tasks Performed
- Database creation
- Data validation
- Duplicate record detection
- Missing value handling
- Data standardization
- Data cleaning
- String functions
- Aggregate functions
- Filtering and sorting
- Data type validation
- NULL value checking
- Data quality checks
